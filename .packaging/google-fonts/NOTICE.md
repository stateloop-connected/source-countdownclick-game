# Self-hosted Google Fonts

Added by Stateloop packaging so players' browsers never contact Google. The files are the exact
stylesheets and WOFF2 files Google Fonts serves for the game's own font request; each family keeps
its licence from google/fonts at e7db6ca603fd4862010383ff17ffd6cc4ffac1c0.

- Handjet: OFL-1.1 (google/fonts `ofl/handjet/OFL.txt`)
- Quicksand: OFL-1.1 (google/fonts `ofl/quicksand/OFL.txt`)

Source stylesheets:

- `https://fonts.googleapis.com/css2?family=Quicksand:wght@400;700&family=Handjet:wght@400;700&display=swap` (sha256 ecdfea3dff2174089678e78937f890a39df91f007acbe7f33a702ec79c25a11a)
